# Git LFS Server

Bring Your Own Forge (BYOF) Git LFS server with affordable storage.

## Price comparison

Assuming 1 TiB is uploaded and stored for a full month, and 3 TiB is downloaded in the same month:

| Provider | Storage | Download bandwidth | Monthly total | Savings vs. GitLab LFS |
| --- | ---: | ---: | ---: | ---: |
| GitLab LFS | 109 x 10 GB-month x $5 = $545.00 | Included | $545.00 | Baseline |
| GitHub LFS | 1,014 GiB x $0.07 = $70.98 | 3,062 GiB x $0.0875 = $267.93 | $338.91 | $206.09 (37.81%) |
| Cloudflare R2 Standard | 1,090 GB-month x $0.015 = $16.35 | Included | $16.35 | $528.65 (97.00%) |
